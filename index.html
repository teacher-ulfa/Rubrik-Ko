Cara Menghubungkan ke Spreadsheet

  1. Buat Google Spreadsheet baru.
  2. Buat Header di Baris 1 (Penting: Huruf kecil semua sesuai `name` di input): timestamp, tanggal, nama_juri, kelas, aspek_1, aspek_2, aspek_3, aspek_4, aspek_5, total_score.
  3. Klik menu Ekstensi > Apps Script.
  4. Hapus kode yang ada, lalu *paste* kode dari file Code.gs yang diberikan oleh AI.
  5. Simpan (Ctrl+S).
  6. Jalankan fungsi initialSetup sekali saja. Akan muncul pop-up izin, setujui (lanjutkan ke tidak aman/advanced).
  7. Klik tombol Terapkan (Deploy) di pojok kanan atas > Deployment baru.
  8. Pilih jenis: Aplikasi Web.
  9. Akses: Pilih Siapa saja (Anyone).
  10. Klik Terapkan. Salin URL Aplikasi Web.
  11. Buka kembali file index.html (di editor atau GitHub), cari variabel scriptURL di bagian bawah (JavaScript), ganti nilainya dengan URL yang baru Anda salin.
